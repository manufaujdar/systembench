# Documentation index

SystemBench is a provider-neutral Python framework for evaluating complete AI
systems. It measures outcomes, process, operations, reliability, and failure
recovery; it is not a claim that any benchmark suite is valid by default.

## Authoritative documents

- README.md: quick start, architecture sketch, reports, and current status.
- docs/DESIGN.md: scenarios, metrics, uncertainty, comparisons, and roadmap.
- docs/architecture.md and docs/technical-overview.md: software baseline.
- examples/ and tests/: executable examples and contract evidence.
- AGENTS.md, .ai/, and .agents/skills/: suite design and validity review rules.
